# Random Graph Lab

A sandbox project for learning AI-assisted software development.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)

## Frontend

```bash
cd frontend
npm ci
npm run dev
```

Other commands:

```bash
npm run lint    # ESLint
npm test        # Vitest (single run)
npm run build   # Typecheck + production bundle
npm run preview # Preview production build locally
```
